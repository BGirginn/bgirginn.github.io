Research and Competition

Case studies

An automated control system developed for Talu Textile as part of a TUBITAK-funded research project. It uses LoRa wireless communication to connect factory equipment across large industrial spaces.

Project overview

  • Started in November 2024 as part of the TUBITAK grant program.
  • Developed with Talu Textile for a practical industrial deployment context.
  • Designed to replace rigid wired control systems with a flexible LoRa network.
  • Focused on range, reliability, and low-power operation.

System architecture

  • Communication: LoRa long-range wireless protocol.
  • Nodes: ESP32 microcontrollers for sensor and actuator control.
  • Gateway: Raspberry Pi for data aggregation and processing.
  • Software: C++ firmware and Python gateway services.

Technical implementation

  • Custom LoRa network protocol tuned for factory conditions.
  • ESP32 nodes handle local readings and actuator commands.
  • Raspberry Pi gateway aggregates node data for a monitoring dashboard.
  • Failsafe behavior for critical control actions.
Open repository

A robotics project built for Biga ICDAS Science High School's competition. The vehicle simulated a space mining rover with wireless control, object manipulation, and autonomous navigation.

Project context

  • Developed between April and May 2020.
  • Competition theme: autonomous space mining vehicle prototype.
  • Completed all assigned missions with the highest accuracy.

Hardware components

  • Arduino controller with Bluetooth remote control.
  • Infrared, ultrasonic, and LIDAR sensors for navigation.
  • Motor-driven robotic arm with pressure-sensitive gripper.

Key features

  • Line following using LIDAR scanning.
  • Object detection and distance measurement.
  • Wireless manual override and autonomous waypoint movement.
